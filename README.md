I build the part that has to still be true when nobody is watching. Rust, single static binary,
Apache-2.0. The limits are written down before the features are, and a test fails if the written
limits drift from the code that enforces them.

Not released yet — what is on crates.io and npm under that name is a reservation holding the name,
and the front page says so in the first thing you read.

## What is actually mine here

Most repositories on this account are working copies of other people's projects, kept for reading
and for preparing pull requests. GitHub does not label all of them as forks, so it is worth saying
plainly rather than leaving it to be inferred.

Mine: **[TraceFold/tracefold](https://github.com/TraceFold/tracefold)**, pinned above. Everything else is a fork or a working copy of
someone else's work, and the licence on it is theirs.
