# mahirhir

Independent. Not chasing the timeline.

Building [Tracefold](https://github.com/TraceFold/tracefold) — verified undo and offline-verifiable receipts for AI agent actions. An agent's change is escrowed with a checked inverse before it lands, and every verdict becomes a receipt a third party can verify offline.

Rust. Single static binary. Apache-2.0. Limits documented before features.

Glovrex — mahirhir@glovrex.com
