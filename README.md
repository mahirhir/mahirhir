## What I am building

**[Tracefold](https://github.com/TraceFold/tracefold)** — verified undo for AI agent actions. A change is held with a checked
inverse **before** it lands, and every verdict becomes a receipt a third party can re-check
offline, without trusting whoever issued it.

Rust, single static binary, Apache-2.0. The limits are written down before the features are,
and a test fails if the written limits drift from the code that enforces them.
